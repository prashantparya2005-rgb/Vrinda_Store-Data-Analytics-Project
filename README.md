# 📊 Vrinda Store – Data Analytics Project

> Turning raw e-commerce data into meaningful business insights using Microsoft Excel.

---

## 📌 Project Overview

The **Vrinda Store Data Analytics Project** is an Excel-based data analysis project focused on understanding sales performance, customer demographics, order information, product categories, and geographical distribution.

The project transforms raw e-commerce order data into meaningful insights using **data cleaning, Pivot Tables, Pivot Charts, Slicers, and interactive dashboards**.

The dataset contains important fields such as Order ID, Customer ID, Gender, Age, Order Status, Sales Channel, SKU, Category, Quantity, Amount, City, State, and Country. :contentReference[oaicite:1]{index=1}

---

## 🎯 Business Objective

The main objective of this project is to analyze store sales data and answer important business questions such as:

- Who are the major customers?
- Which gender contributes more to sales?
- Which age groups purchase the most?
- Which product categories perform better?
- Which sales channels generate more orders?
- Which states contribute significantly to sales?
- What is the overall order and sales performance?

## 🧹 Data Preparation

Before creating the dashboard, the raw dataset was prepared for analysis.

### Data Preparation Activities

- Removed unnecessary/duplicate records
- Checked data consistency
- Verified missing values
- Standardized data formats
- Organized sales and customer information
- Prepared the dataset for Pivot Table analysis
